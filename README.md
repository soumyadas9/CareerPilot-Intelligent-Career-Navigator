# CareerPilot – Intelligent Career Navigator

## Overview
An explainable career recommendation platform
for students and early-career professionals.

## Problem Statement
Students struggle to identify suitable roles,
understand skill gaps and plan their next steps.

## Features
- Explainable job matching
- Weighted match scores
- Skill-gap analysis
- Personalized learning roadmap
- Resume keyword analysis
- Interview preparation
- Job source and freshness indicators
